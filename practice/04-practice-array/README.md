## Практическое задание №1. Баллы за задания

1. Создайте массив. Объявите константу constexpr int size = 4; и массив int
scores[size]{};. Фигурные скобки задают начальные нули.

2. Заполните массив. С помощью цикла for запросите четыре целых балла от 0 до 100.
Сохраняйте каждый балл в элементе scores[i]. Для баллов предполагается корректный
ввод.

3. Покажите результаты. Выведите все четыре значения в порядке ввода, используя
цикл. Разделяйте числа пробелами.

4. Запросите номер. Считайте номер задания от 1 до 4. Проверьте диапазон через if. При
допустимом номере используйте индекс number - 1. При неверном номере выведите
сообщение об ошибке.

Пример работы программы

```
--- Баллы за задания ---
Балл 1: 70
Балл 2: 85
Балл 3: 90
Балл 4: 60
Баллы: 70 85 90 60
Номер задания (1-4): 3
Балл за задание 3: 90
```

## ПРАКТИЧЕСКОЕ ЗАДАНИЕ 02

Температура за шесть часов
Имя файла: temperatures.cpp. Напишите программу, которая хранит шесть целых
температурных измерений, рассчитывает статистику и показывает количество
положительных значений. Ориентировочно 12–15 минут.

Порядок выполнения

1. Подготовьте массив. Объявите константу размера 6 и массив int. Запросите шесть
измерений в диапазоне от −50 до 50. Используйте цикл for и сохраните каждое число в
очередной ячейке. Ввод считается корректным.

2. Подготовьте накопители. Создайте переменные sum и positive со значением 0. Для
minValue и maxValue возьмите значение первого элемента уже заполненного массива.

3. Обойдите массив. В новом цикле переберите все элементы. Прибавляйте каждый к
sum. Если текущее число меньше minValue, обновляйте минимум; если больше maxValue,
обновляйте максимум. При значении строго больше нуля увеличивайте positive.

4. Рассчитайте среднее. Разделите сумму на размер массива, предварительно
преобразовав её через static_cast<double>(sum). Подключите <iomanip> и используйте
std::fixed и std::setprecision(2) для вывода среднего с двумя знаками после точки.

5. Выведите результат. Покажите сумму, минимальную и максимальную температуру,
среднее и количество положительных измерений.

Пример работы программы

```
--- Температура за шесть часов ---
Введите 6 температур:
-3 0 7 12 -2 4
Сумма: 18
Минимум: -3
Максимум: 12
Среднее: 3.00
Положительных: 3
```
Подсказка. Инициализация минимума или максимума нулём может привести к ошибке,
если все значения положительные или все отрицательные. Возьмите первый элемент
массива.

## ПРАКТИЧЕСКОЕ ЗАДАНИЕ 03

Поиск и замена элемента
Имя файла: inventory.cpp. Создайте программу учёта пяти значений остатков товара.
Пользователь ищет заданное количество и заменяет остаток по номеру ячейки.
Ориентировочно 13–15 минут.

Порядок выполнения

1. Заполните массив. Создайте массив int из пяти элементов. С помощью цикла
прочитайте пять целых остатков от 0 до 1000. Ввод остатков считается корректным.

2. Запросите искомое значение. Считайте целое число target. Создайте переменную
found со значением −1. Обойдите массив циклом for. Если элемент равен target, запишите
его индекс в found и завершите цикл через break.

3. Покажите результат поиска. Если found равен −1, выведите «Значение не найдено».
Иначе выведите номер первой подходящей ячейки: found + 1. При нескольких совпадениях
сообщайте только о первом.

4. Измените остаток. Запросите номер ячейки от 1 до 5 и новое значение от 0 до 1000.
Проверьте оба диапазона. При допустимых данных присвойте новое значение элементу с
индексом number - 1. При ошибке сохраните массив и выведите сообщение.

5. Проверьте изменение. Выведите все элементы массива после попытки замены.
Используйте цикл for.

Пример работы программы:

```
--- Остатки товара ---
Введите 5 остатков:
10 25 10 0 8
Искомое значение: 10
Первое совпадение: ячейка 1
Номер ячейки (1-5): 4
Новый остаток: 12
Массив: 10 25 10 12 8
```
