Три задания на 90 минут · C++23

Группа 9/2-РПО-25/1 · МДК.01.05 Основы программирования на языке C++

Создайте три консольные программы: паспорт студента, заказ в учебном кафе и билет участника. Вы примените структуру программы, переменные, константы, инициализацию, присваивание, копирование значений и простые вычисления. Для числовых и логических данных используйте **int**, **double** и **bool**. Текст храните в **std::string**, вводите целыми строками и выводите в консоль.

Подготовка

В папке practice/02-console-output/ создайте подпапки task01-profile, task02-cafe и task03-ticket со своим main.cpp в каждой. Общий report.md разместите в practice/02-console-output/. Каждое задание собирайте как отдельный проект или отдельную цель сборки со своей функцией **main**.

Выберите C++23; по указанию преподавателя допустим C++20. Подключите заголовки <iostream> и <string> и проверьте сборку каркаса. В Visual Studio сохраняйте изменения через Ctrl+S, запускайте через Ctrl+F5.

Короткая памятка

Тип **int** используйте для целых чисел, **double** — для чисел с дробной частью, **bool** — для значений **true** и **false**. Дробную часть отделяйте точкой. Пометка **const** задаёт константу с начальным значением. Для проверки нового варианта задавайте другие начальные данные перед сборкой.

Тип **std::string** хранит текст с пробелами. Функции **getline** ****передайте поток **std::cin** и строковую переменную для ввода. Сначала выведите приглашение, затем прочитайте строку; Enter завершает ввод. Так вводятся имя, группа, название блюда и события. Числа и логические значения задаются при создании переменных.

Выводите строки целиком через **std::cout** с подписями. Манипулятор **std::boolalpha** в потоке вывода включает отображение логических значений словами true и false.

Присваивание изменяет значение существующей переменной. Копия получает значение в момент копирования. В заданиях 1 и 3 проследите значения до присваивания и после него.

Задание 1 Паспорт студента

Время — 25 минут. Создайте программу Profile, которая получает имя и группу, выводит данные студента и показывает изменение счётчика выполненных заданий.

Исходные данные

| **Данные** | **Тип** | **Начальное значение** |
| --- | --- | --- |
| Имя и фамилия | **std::string** | Вводятся с клавиатуры |
| Группа | **std::string** | Вводится с клавиатуры |
| Возраст | **int** | 16 |
| Опыт обучения в годах | **double** | 1.5 |
| Готовность к проекту | **bool** | false |
| Количество пройденных пар | **const** **int** | 2 |
| Счётчик выполненных заданий | **int** | Ноль при инициализации |
Порядок выполнения

1. Создайте каркас программы и объявите данные из таблицы. Для числового счётчика примените инициализацию пустыми фигурными скобками. Для возраста, опыта, готовности и количества пар задайте указанные начальные значения. Подберите понятные имена.

2. Выведите приглашения Name и Group. После каждого приглашения прочитайте соответствующую строку с помощью **getline**. 

3. Создайте ещё одну целочисленную переменную и скопируйте в неё текущее значение счётчика. Выполните копирование до изменения счётчика. Эта переменная хранит сохранённый результат.

4. Выведите пустую строку, заголовок STUDENT PROFILE и данные паспорта с подписями. Для опыта добавьте единицу years. Изучаемый язык C++ выведите как обычный текст. 

5. Покажите счётчик до изменения. Затем отдельным присваиванием установите значение 3. Выведите новое значение счётчика и сохранённую ранее копию.

6. Соберите программу и сверьте результат с примером. Проведите второй запуск по условию ниже. В отчёте поясните выбор типов для возраста, опыта и готовности.

Задание 2 Заказ в учебном кафе

Время — 25 минут. Создайте программу CafeOrder. Пользователь вводит имя покупателя и название блюда. Программа выводит заказ, рассчитывает стоимость порций и итог со сбором, показывает состояние оплаты.

Исходные данные

| **Данные** | **Тип** | **Начальное значение** |
| --- | --- | --- |
| Имя покупателя и название блюда | **std::string** | Вводятся с клавиатуры |
| Цена одной порции | **const** **double** | 145.5 |
| Количество порций | **int** | 3 |
| Сбор за весь заказ | **const** **double** | 20.0 |
| Состояние оплаты | **bool** | false |
Рассчитайте стоимость всех порций умножением цены одной порции на количество. Затем прибавьте сбор за весь заказ один раз. Оба результата сохраните в отдельных переменных **double**. Состояние оплаты в этой версии отображается как справочная информация.

Порядок выполнения

1. Создайте каркас программы, две строки для ввода и числовые данные из таблицы. Для цены и сбора используйте **const**. Для состояния оплаты задайте логическое значение false.

2. Выведите приглашение Customer и прочитайте имя покупателя через **std::getline**. Затем выведите Dish и прочитайте название блюда целиком. Для контрольного запуска введите Alex и Pasta Carbonara.

3. Сохраните стоимость всех порций в отдельной переменной **double**. Используйте в выражении цену и количество из переменных. Во второй переменной **double** сохраните итог со сбором.

4. Выведите заголовок CAFE ORDER, имя покупателя и блюдо. Затем покажите цену порции, количество, стоимость всех порций, сбор и итог. Для денежных величин укажите RUB. В каждой строке разместите понятную подпись.

5. Выведите состояние оплаты словом с помощью **std::boolalpha**. Добавьте осмысленный комментарий, объясняющий начисление сбора за заказ.

6. Проверьте все три набора данных из таблицы ниже. Перед каждым запуском вычислите итог вручную. Изменяйте начальные значения числовых данных перед сборкой, имя и блюдо вводите при запуске.

7. В отчёте запишите результаты и объясните, почему цена и итог хранятся в **double**, а количество порций — в **int**.

Задание 3 Билет участника

Время — 30 минут. Создайте программу Ticket для оформления заказа на IT встречу. Пользователь вводит имя и название события. Программа рассчитывает сумму и показывает изменение количества выданных билетов и состояния подтверждения.

Исходные данные

| **Данные** | **Тип** | **Начальное значение** |
| --- | --- | --- |
| Имя участника и название события | **std::string** | Вводятся с клавиатуры |
| Цена одного билета | **const** **int** | 200 |
| Количество билетов | **int** | 3 |
| Сбор за весь заказ | **const** **int** | 25 |
| Количество выданных билетов | **int** | Ноль при инициализации |
| Подтверждение выдачи | **bool** | false |
Стоимость всего заказа равна цене одного билета, умноженной на количество, плюс сбор за заказ. Сбор прибавляется один раз. Денежные величины этого задания задаются целым количеством рублей. Результат расчёта сохраните в отдельной переменной **int**.

Порядок выполнения

1. Создайте каркас программы, переменные и константы из таблицы. Прочитайте имя участника и название после соответствующих приглашений. 

2. Рассчитайте итог заказа в отдельной переменной. Перед запуском вычислите сумму вручную для исходных данных 200, 3 и 25.

3. Создайте целочисленную копию счётчика выданных билетов до его изменения. Сохранённая копия должна показывать значение в момент её создания.

4. Выведите пустую строку, заголовок IT MEETUP TICKET, организатора IT Academy как обычный текст, имя и название события. Вокруг названия события выведите двойные кавычки. Затем покажите цену, количество, сбор и итог с единицей RUB для денежных величин.

5. Выведите количество выданных билетов и состояние подтверждения до выдачи. Для **bool** используйте **std::boolalpha**.

6. Присвойте счётчику количество билетов в заказе, а признаку подтверждения — true. Выведите новые значения и сохранённую копию счётчика. Добавьте осмысленный комментарий к расчёту или выдаче билетов.

7. Проверьте три заказа из таблицы ниже. Для каждого задайте нужные начальные значения перед сборкой программы. Для сдачи оставьте цену 200, количество 3 и сбор 25; при последнем запуске введите собственное имя латиницей и выбранное название события.
