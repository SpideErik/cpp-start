# Функциональная декомпозиция CLI-команды




# **Практическая работа** 

Время: 30 минут реализации и 10 минут разбора. Возьмите рабочую типизированную утилиту пары 10\. Если она ещё не закончена, сначала соберите выданный исходник с Command и Status. Сохраните его копию для сравнительной проверки.

## **Условия**

Устройство управляется через команды 0 — выход, 1 — состояние, 2 — запуск, 3 — остановка. Температура читается в начале сеанса и должна входить в диапазон от −50 до 100\. Запуск допускается только при остановленном устройстве и температуре от 0 до 40 включительно. Повторный запуск и выход за диапазон дают отказ. Остановка работает также в состоянии Stopped. Неизвестные команды и отказы не увеличивают счётчик. Лимит успешных команд — 10\. После успешной команды выводится сообщение, затем Running: **true** или Running: **false**.

Правила завершения приложения на этой паре: 0 — штатный выход или достижение лимита; 1 — ошибка чтения; 2 — недопустимая начальная температура. Внутри сеанса ошибка известности команды или отказ запуска позволяют продолжать ввод. Ранее при недопустимой начальной температуре программа возвращала 0; для этой ситуации вводим отдельный код 2\. Консольные сообщения сохраняются.

## **Этап 1 Выделение контрактов**

1\. Просмотрите Command, Status, Temperature, CommandCount и настройки. Сохраните все числовые значения, объявления и ограничения.

2\. Объявите тип CommandError с вариантами None, AlreadyRunning, TemperatureOutsideStartRange. Для результата работы процесса создайте отдельный ExitCode с числами 0, 1 и 2\.

3\. Напишите функцию **isValidTemperature**, которая принимает температуру и возвращает **bool**. Используйте именованные пределы.

4\. Напишите **validateCommand**, которая принимает Command, Status и Temperature. Для Start сначала проверьте, запущено ли устройство, затем температуру. Верните подходящий CommandError. Для ShowStatus и Stop проверка разрешает обработку. Exit проверяется в управляющем цикле до вызова этой функции. Контракт функции: принимается известная команда, допустимая исходная температура и корректное состояние.

5\. Для **executeCommand** определите результат типа Status. Функция получает разрешённую команду и текущее состояние. Start возвращает Running, Stop возвращает Stopped, ShowStatus сохраняет состояние. В вычислении статуса не используйте **std::cin**, **std::cout** или счётчик сеанса.

## **Этап 2 Разделение вывода и управления**

1\. Выделите функцию **printCommandError**. Она получает CommandError и при отказе выводит прежнее Start denied. Оба кода отказа можно обработать отдельно или объединить в **switch**.

2\. Выделите **printCommandResult** для сообщения об успешной команде. Сохраните строки Status, Started и Stopped. Используйте функцию **printStatus** из пары 10 для отображения текущего состояния.

3\. Соберите функцию **runSession**. Она получает проверенную температуру по значению, создаёт исходное состояние и счётчик внутри своей области, организует цикл ввода. При ошибке потока возвращается InputError. При неизвестном коде появляется Unknown command и выполняется **continue** до преобразования числа в Command.

4\. После успешного преобразования проверьте Exit, затем вызовите **validateCommand**. В случае отказа выведите сообщение и перейдите к следующему запросу.

5\. При разрешении вызовите **executeCommand**, присвойте вернувшийся статус переменной, увеличьте счётчик, отобразите результат. После выхода из цикла выведите итоговые Completed и Count.

6\. В **main** оставьте чтение температуры, проверку, вызов **runSession** и преобразование его результата в **int**. Возвратите InvalidTemperature при выходе за допустимый диапазон.

## **Пример работы**

```
Temperature: 20
Command 0/1/2/3: 2
Started Running: true
Command 0/1/2/3: 2
Start denied
Command 0/1/2/3: 1
Status Running: true
Command 0/1/2/3: 3
Stopped
Running: false
Command 0/1/2/3: 0
Completed: 3
Count: 3
```

Код завершения 0. Отказ сохранил предыдущий статус и не увеличил счётчик. Второй пример — температура 101:

Temperature: 101
Invalid temperature

Код завершения 2, приглашения вводить команду не появляется.

## **Этап 3 Проверки**

Используйте отдельную сборку с тестовой **main**, в которой напрямую вызываются чистые функции. Проверьте значения и коды без ввода через консоль. После проверки верните обычную **main**.

| Проверка | Ожидаемый результат |
|---|---|
| **validateCommand**(Start, Stopped, 0\) | None |
| **validateCommand**(Start, Stopped, 40\) | None |
| **validateCommand**(Start, Stopped, 41\) | TemperatureOutsideStartRange |
| **validateCommand**(Start, Stopped, \-1) | TemperatureOutsideStartRange |
| **validateCommand**(Start, Running, 20\) | AlreadyRunning |
| **validateCommand**(ShowStatus, Running, 80\) | None |
| **executeCommand**(Start, Stopped) | Running |
| **executeCommand**(Stop, Running) | Stopped |
| **executeCommand**(ShowStatus, Running) | Running |
| **isValidTemperature**(-50), **isValidTemperature**(100) | **true**, **true** |
| **isValidTemperature**(-51), **isValidTemperature**(101) | **false**, **false** |

В таблице имена перечислителей сокращены для удобства чтения; в C++ используйте квалифицированные Command::Start, Status::Stopped и остальные полные имена.
